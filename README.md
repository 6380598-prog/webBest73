# WebBest — статический сайт

## Публикация через GitHub Pages

1. Распакуйте архив.
2. Загрузите содержимое папки `webbest-site` в корень нового GitHub-репозитория (кнопка **Add file → Upload files**). В корне репозитория должен лежать `index.html`.
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
4. После публикации GitHub покажет адрес сайта в этом же разделе.

Сайт собран из обычных HTML, CSS, JavaScript и файлов в `assets`. Сборка через Node.js не нужна.
