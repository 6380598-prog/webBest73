# WebBest — статический сайт

## Публикация через GitHub Pages

1. Распакуйте архив.
2. Загрузите содержимое папки `webbest-site` в корень репозитория. В корне должен находиться `index.html`.
3. В GitHub откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
4. Адрес сайта появится в разделе Pages после публикации.

Сборка через Node.js не нужна.
